# 工位看盘

隐蔽、轻量的 Windows 桌面行情助手 —— 常驻托盘的自选盯盘工具。

---

## 简介

工位看盘把「现在什么价、涨了多少、要不要提醒」压缩成一块常驻桌面的小浮窗，
需要细节时再打开完整窗口。它面向**盯自己那几只票**的场景，而不是做行情终端。

三条设计底线：

- **不打扰** —— 不登录、不上报、没有账号体系，行情直连公开接口，配置只落在本机
- **不打闲时流量** —— 只在交易时段请求，收盘后补抓一次最终价，其余时间完全静默
- **单点故障不致命** —— 多路行情通道并行取数、按只合并，一条挂掉其余照常

支持 **A 股 / 港股 / 美股 / 东方财富板块** 四类标的。

## 功能

| 模块 | 说明 |
| --- | --- |
| 自选行情 | 代码 / 名称 / 拼音缩写联想添加，覆盖股票、ETF、LOF、可转债、港股、美股、板块 |
| 多市场 | A 股、港股、美股、板块各有独立行情通道与显示精度（港股/美股 3 位小数） |
| 交易时段感知 | 三个市场各按自己的时段请求，非交易时段状态栏明确标注 |
| 指数看板 | 内置 14 个常用指数，可自行勾选启停，支持拖拽排序 |
| 桌面浮窗 | 透明置顶，指数在上、个股在下，高度自适应内容，不遮挡下方窗口 |
| K 线 / 分时 | 自选行点 K 线图标开独立窗口，分时 / 日K / 周K / 月K，含均线与成交量副图 |
| 价格提醒 | 七类条件：上破价、下跌价、涨幅、跌幅、涨跌停、成交量异动（量比）、N 分钟急涨急跌 |
| 提醒通道 | Windows 桌面通知 + 提示音，可分别试听，同一只 5 分钟内不重复轰炸 |
| 无边框窗口 | 四个窗口自绘标题栏，圆角 + 描边，可拖边缩放，标题栏常驻时段与涨跌家数 |
| 深色监控面板 | 深底、等宽数字、紧凑行，深浅两套主题均重新排版 |
| 网络代理 | 跟随系统 / 不使用 / 手动指定，内置连通性测试 |
| 诊断 | 一键查看各通道状态、报错原因与代理实际走向，另有 8 路接口自检 |
| 检查更新 | 启动后静默检查（20 小时一次），也可手动检查并跳转下载 |

## 使用

### 常用操作

| 操作 | 方式 |
| --- | --- |
| 添加自选 | 自选区右上角输入代码 / 名称 / 拼音，回车或点选下拉项 |
| 添加港股 | 输入 5 位代码（00700）或名称（腾讯控股） |
| 添加美股 | 输入字母代码（AAPL）或名称（苹果） |
| 添加板块 | 输入板块名（银行Ⅱ）或 `BK`+4 位代码（BK0475） |
| 调整顺序 | 按住自选行或指数卡片拖动（按钮与输入框区域除外） |
| 切换浮窗 | `Ctrl+Shift+M`，或主界面标题栏「浮窗」按钮 |
| 隐藏浮窗 | `Esc` |
| 移动 / 缩放 | 拖标题栏移动，拖窗口边缘或四角缩放 |
| 收起程序 | 标题栏 `✕` 收进托盘，不退出 |
| 查看 K 线 | 自选行尾的 K 线图标，独立窗口内切换周期 |
| 设置提醒 | 自选行尾的铃铛，打开「价格提醒」窗口 |
| 浮窗右键 | 刷新、显示主窗口、设置、隐藏 / 停用浮窗、退出 |
| 查看诊断 | 点击标题栏左侧圆点，或异常时出现的黄色提示 |
| 退出程序 | 托盘图标右键 → 退出 |

### 数据来源

行情按 **东方财富 → 新浪** 两路并行拉取、按只合并：任一路先返回即采用，并可相互补全，
单条通道故障不影响其他通道。搜索按 **腾讯 → 东财 → 新浪 → 雪球 → 纯代码直通** 多层兜底。

| 通道 | 地址 | 覆盖范围 |
| --- | --- | --- |
| 东方财富 | `push2.eastmoney.com` | A 股 / 港股 / 美股 / 指数 / 东财板块（主力） |
| 新浪 | `hq.sinajs.cn` | A 股 / 港股 / 美股 / 指数（备份） |

两路都是**批量接口**：东方财富用 `ulist.np` 一次取回全部自选与指数，新浪一次请求拿全部，
因此一轮刷新只发 **2 个 HTTP 请求**，而不是每只股票一个 —— 对行情站点的压力降一个数量级。
东方财富另有备用域名 `push2delay.eastmoney.com`。

K 线与分时走东方财富历史接口（`push2his.eastmoney.com`），仅在打开图表窗口时按需请求。

> 所有请求均指向公开行情接口，仅用于个人学习与自用。

### 交易时段

请求时间按北京时间判断，与本机时区无关。三个市场各有一条轨，
**自选里真的有对应市场的标的才会启用该轨**：

| 市场 | 交易时段（北京时间） | 收盘后 |
| --- | --- | --- |
| A 股 | 09:15–11:30、13:00–15:00 | 15:00–15:30 补抓一次最终价 |
| 港股 | 09:30–12:00、13:00–16:00 | 16:00–16:30 补抓一次最终价 |
| 美股 | 21:30–04:00（夏令时）/ 22:30–05:00（冬令时） | 收盘后 30 分钟内补抓一次 |

午休、周末、法定节假日不发请求。美股的夏令时切换（3 月第二个周日 ↔ 11 月第一个周日）
与美股节假日全部按规则自动计算，不需要每年手工维护表。

非交易时段状态栏会显示「午间休市」「已收盘」「周末休市」等状态，
数据不再变化属正常现象。该行为可在设置中关闭。

## 配置与隐私

- 配置只保存在本机：`%APPDATA%\工位看盘\gongwei-stocks.json`
- 不向任何服务器上传用户数据，没有遥测与崩溃上报
- 绿色单文件版目前仍写 `%APPDATA%`，「便携版数据本地化」在路线图上

## 常见问题

**状态显示「来源 none」并提示异常？**
两条通道同时失败，通常是网络问题：断网、切换网络，或公司网络拦截了行情站点。
点击标题栏左侧圆点查看诊断；若已配置代理，先用设置里的「测试连通性」确认哪条通道不通。

**美股 / 港股搜得到却看不到数据？**
属于 secid 推断错误。程序会自动换候选市场号重试并缓存结果；
若长期取不到，用「接口自检」确认该通道是否可达。

**个别指数一直显示 `--`？**
少数指数仅由单一通道提供（例如中证 2000 依赖东方财富），该通道不可用时它们显示 `--`，
其余指数正常。

**首次运行提示「未知发布者」？**
安装包未购买代码签名证书，Windows SmartScreen 会给出该提示，
点击「更多信息 → 仍要运行」即可。

**关闭窗口后程序去哪了？**
在系统托盘。标题栏的 `✕` 与关窗口一样是收进托盘，右键托盘图标可退出。

## 开发

```bash

npm start       # 本地运行
npm test        # 打包配置校验 + 静态审计 + 行情/提醒单测 + DOM 交互测试
```
